# FRIO brand mark

## Files

- `frio-logo-primary.svg` — framed primary lockup for labels, title pages, and packaging fronts.
- `frio-logo-square.svg` — 1:1 lockup for profile images, caps, cartons, and square panels.
- `frio-logo-square.png` — 2400 × 2400 px square raster export.
- `frio-wordmark.svg` — compact transparent wordmark for headers and small horizontal spaces.

## Palette

| Name | Hex | Suggested use |
| --- | --- | --- |
| Frio Teal | `#126E70` | Primary wordmark and frame |
| River Cream | `#F3E7D1` | Label stock and current channel |
| Burnt Orange | `#C65F32` | Current line and small accents |

The main FRIO letterforms are SVG paths and do not require a font. The supporting microtype uses Arial/Helvetica fallbacks to keep the asset lightweight and broadly portable.
